# Commit Message Convention
- 형식: `{이모지}{TYPE}: {설명} (#{이슈번호})`
  - 예시: `✨FEAT: 로그인 API 연동 (#12)`

| **이모지** | **타입** | **사용 상황** |
| :---: | :--- | :--- |
| ✨ | **FEAT** | 새로운 기능 추가 |
| 🐛 | **FIX** | 버그 수정 |
| 📝 | **DOCS** | 문서 수정 (README, 노션 링크, 수행계획서 등) |
| 🎨 | **STYLE** | 코드 포맷팅, UI 디자인 수정 (로직 변경 없음) |
| ♻️ | **REFACTOR** | 코드 리팩토링 (성능 개선, 가독성 향상) |
| ✅ | **TEST** | 테스트 코드 추가 및 수정 |
| ⚙️ | **CHORE** | 빌드 업무, 패키지 매니저, .gitignore 수정 |
| 💬 | **COMMENT** | 주석 추가 및 변경 |
| 🌱 | **BUILD** | 빌드 관련 파일 수정 (예: Gradle) |
| ⏪ | **REVERT** | 이전 커밋 되돌리기 |
